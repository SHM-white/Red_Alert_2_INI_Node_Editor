# Modern RINE 后续开发路线

## 本 PR 已覆盖

- Qt 6/CMake/C++20 独立构建，去除对遗留 ImGui/VS 工程的运行时依赖。
- 可逆的 INI 字节级加载/保存、保持注释与文件编码，文件原子保存。
- 搜索/类型筛选/节点关系图/属性编辑、增删重命名、撤销重做。
- 3 套主题、保存设置、Windows Qt DLL 打包、测试与 Actions 自动化。

## 优先级 P1 · 文档健壮性

- [ ] 可选编码 GB18030 / CP936 / UTF-8 与显式重编码。
- [ ] 多文件工作区（rulesmd.ini、artmd.ini、ai.ini 等）、基于 include 的跨文件引用。
- [ ] 将编辑命令改为行级 UndoCommand，降低极大文件的撤销内存开销。
- [ ] 为添加/删除节恢复关联引用、识别复杂值列表和重复节语义。
- [ ] 基于真实 Mod INI 增加编码、注释、复合值、特殊键及极大文件的基准测试。

## 优先级 P2 · 可视化与编辑功能

- [ ] 更完整的类型分类（InfantryTypes、VehicleTypes、OverlayTypes 等），可编辑规则词典。
- [ ] 更丰富的关系边标签、筛选、二级深度、渐进式布局与视图稳定化。
- [ ] 属性值的类型化编辑控件（布尔、数字、枚举、对象引用、颜色）。
- [ ] 节点复制粘贴、批量属性操作、跨文件搜索和跳转。
- [ ] 文件诊断（未定义引用、重复定义、循环引用）与快速修复。
- [ ] 对比/差异视图、工作区最近文件、可自定义快捷键。

## 兼容性原则

1. 不静默丢失注释、编码、行序及未知键。
2. 将“对象类型”作为可配置显示属性，不把启发式识别当作游戏语义真值。
3. 对大 INI 文件默认只渲染邻接子图，不渲染全量关系图。
4. 每项涉及写入的功能补回归测试。
